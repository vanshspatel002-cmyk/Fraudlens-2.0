# Authorized presentation photographs

Photographs: **Milkmandan~commonswiki**, Wikimedia Commons, Chevrolet Classic
series, May 2005. Licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
Original files are unmodified; attribution and individual source pages follow.
Retain this attribution and license when sharing these photographs or derivative graphics.

The original series, matching car details, setting and capture metadata support
use as a same-vehicle presentation set. This is not independent ownership,
registration, date, current-condition or policy verification. Public US plates
do not validate a fictional Indian registration. The odometer display is off.
No physical damage or repair estimate is established by these photographs.

**Claims (4):** front-right = overview; left = mounted front registration;
interior = interior concern overview; door = vehicle-part close-up. The fictional
application reports an unconfirmed electrical/window concern, not visible crash damage.

**Underwriting (6):** left/front-right/rear-left/rear-right, gauges, straight rear
registration. These are distinct files, not six copies. Labels are applicant
assignments; the gate checks relevance, not independently established view angle.
An unreadable odometer remains a material assessment gap.

Keep these outside production reference ingestion. The rehearsal uses a separate
PostgreSQL schema and evidence directory. Shared photographs may reuse compatible
perception caches; verification records identify fresh versus cached observations.
