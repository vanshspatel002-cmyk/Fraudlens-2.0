Source-reference rows are an audit index, not invented external verification. `declared_time` is an aware instant in production; the legacy generated corpus uses local wall-clock semantics. Underwriting amount zero is not a claims-damage input: production policy excludes damage_plausibility and threshold_gaming. Current customer UI does not collect coordinates; location text is not geocoded. Scene assessment consequently abstains, a material limitation. Bank last four is a weak relationship, never proof of identity. Policy, DOB, licence, address, RTO and FIR declarations have no authoritative external verification. No field is artificially forced into risk. Image labels do not authenticate views or same vehicle.

Coordinate contract now rejects partial, NaN/infinite and out-of-range pairs before admission. Omitted coordinates remain permitted and explicitly insufficient for scene comparisons. `Idempotency-Key` is a generated UUID4 operational header stored with submission receipts, not risk evidence. Photo slots are customer workflow labels; the API stores supplied photographs, not independent view/vehicle authentication. Occurrence-based frontend references can include reviewer display code; they are not all customer form inputs.
